# Same-origin Accounting transport

AR/AP service calls /api/accounting on the app origin. The catch-all route forwards
that namespace to NEXT_PUBLIC_API_URL (default localhost5001) on the server. This
removes the browser's separate connection to the backend port; it does not replace
backend authorization, tenant resolution, plan gates or financial services.

Forward only bearer/content-type/tenant-slug/MFA/CSRF headers. Do not forward
browser cookies or follow upstream redirects. Preserve upstream status/body,
query and write payload, use no-store, and reject unsafe path segments. There is
no server-minted token or implicit cookie authentication. Backend URL must point
to the backend API, not this catch-all route.

No write retries. A dropped write response cannot prove whether it committed:
return an unconfirmed-action message asking for refresh before another attempt.
Reads return503 with a readable unavailable message. No receipt, allocation,
credit, refund or journal is generated by this transport layer.
