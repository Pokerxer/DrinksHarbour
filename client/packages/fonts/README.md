# Application fonts

Google Fonts Latin WOFF2 files, retrieved 19 October 2026 for self-hosted builds. Families and styles preserve the existing design: Inter, Lexend Deca, Fraunces normal/italic, Elms Sans and Kavoon. Variable weight ranges are declared in each application font module. Redistribution licences sit beside each family. Sources: https://fonts.google.com and https://github.com/google/fonts/tree/main/ofl. No Google network call is required during build.
